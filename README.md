# COS214 Practical 2 — Wayfarer

Menu-driven traveller demo for Pretoria. Patterns used: Composite (map), Decorator (university / fuel / attraction), State (walk / dash / teleport / swim), Strategy (route), Abstract Factory (biome, NPC, obstacle).

## Requirements

- `g++` with C++11
- `make`
- Linux or WSL (this is how the makefile is meant to be run)

## Build and run

From the project folder (`COS214_Prac2`), **not** from a flattened zip of loose files:

```bash
make clean
make run
